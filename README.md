# MAX_dot_GRAIN

A granular sampler and audio-reactive video instrument by joyfm, built to run on a dedicated tablet.

- Two sample slots (tap A or B to load a WAV/MP3/M4A, hold to mute), each with EmissionControl2-style grain controls and its own filter
- Four tap-handle knobs for delay rate, feedback, reverb pre-delay and decay
- An LCD showing both samples, the scan regions, the playhead and grains as they fire
- Tap **MAX** for the HAPTIC DOT NOISE video, driven by the sound: loudness, frequency bands, scan heads, hits and delay feedback
- Drag the dot to freeze and scrub the grains, pinch to change dot size and grain length, flick to scatter, tilt for pitch and filter

## Install on a tablet
Open the GitHub Pages link in Safari (iPad) or Chrome (Android), then choose **Add to Home Screen**. It launches full screen and works offline.
